## Description

Quiero una historia para mejorar el espacio interno de los widget, el de los padding con los bordes. El contenido del widget (icono, temperatura, descripción del clima, ubicación, reloj, fecha) está pegado o muy cerca de los bordes del widget, dando una sensación de espacio interno pobre/apretado. Se necesita ajustar el padding interno del layout del widget (Glance) para dar más aire entre el contenido y los bordes del contenedor, mejorando la legibilidad y el aspecto visual general.

El usuario adjuntó una imagen de referencia mostrando el widget actual (tema oscuro, fondo negro redondeado) con el icono de clima, "29.1°C", "Chubasco moderado o inte...", "Carrasquilla" alineados a la izquierda y un reloj analógico + fecha "Wed, 19 Aug" a la derecha — el contenido se ve pegado a los bordes del contenedor del widget, especialmente arriba/izquierda.
